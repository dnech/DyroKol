# Аналоги и сравнение

DyroKol — самохостируемый проброс TCP-портов с веб-интерфейсом (по назначению близок к обратным прокси, туннелям и инструментам обхода NAT). Похожие проекты, чтобы вы могли выбрать подходящий:

| Инструмент | Что это | Чем отличается DyroKol |
| --- | --- | --- |
| [frp](https://github.com/fatedier/frp) | Обратный прокси / проброс портов: сервер (`frps`) и клиенты (`frpc`), настройка файлами | DyroKol управляется из веб-интерфейса со схемой маршрутов, relay сразу рассылает изменения агентам; номер порта уникален в пределах машины |
| [rathole](https://github.com/rapiz1/rathole) | Лёгкий и быстрый обратный прокси для обхода NAT | DyroKol менее минималистичен: интерфейс, фильтры, статистика, зашифрованная база конфигурации |
| [ngrok](https://ngrok.com/) | Облачные туннели с публичными адресами | DyroKol поднимается у вас: ваш VPS, ваш сертификат, нет сторонних сервисов на пути трафика |
| [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) | Исходящие туннели, публикуемые через Cloudflare | Не нужны аккаунт и третья сторона; обычные TCP-порты, не только HTTP(S) |
| [Tailscale](https://tailscale.com/) / [WireGuard](https://www.wireguard.com/) | Mesh-VPN / VPN | DyroKol не VPN: он пробрасывает отдельные TCP-порты, ничего не ставится на уровне ОС, нет виртуальных адаптеров |
| [chisel](https://github.com/jpillora/chisel) | TCP/UDP-туннель поверх HTTP с шифрованием SSH | В DyroKol есть централизованные маршруты, фильтры источника и назначения и интерфейс |
| [bore](https://github.com/ekzhang/bore) | Минимальный TCP-туннель на публичный сервер | DyroKol управляет многими портами и машинами из одного места |
| [sshuttle](https://github.com/sshuttle/sshuttle) | «VPN для бедных» поверх SSH: прозрачно направляет целые подсети через SSH-сервер | sshuttle нужны SSH-доступ и root на клиенте, он ведёт сети от клиента наружу; DyroKol пробрасывает выбранные TCP-порты, агенты сами подключаются наружу и не требуют SSH и прав администратора |
| `ssh -R` / autossh | Обратный проброс портов через SSH | Не нужно писать команды и перезапускать их для каждого порта; маршруты правятся в интерфейсе |

Выбирайте DyroKol, если нужно **пробрасывать TCP-порты между своими машинами через один публичный
сервер, управлять этим из браузера и иметь встроенный SOCKS5-выход** без VPN. Если нужны UDP,
HTTP-имена с автоматическими сертификатами или полноценная mesh-сеть, лучше взять другой инструмент.

Сравнение краткое, по публичным описаниям проектов; актуальные возможности смотрите у каждого из них.
